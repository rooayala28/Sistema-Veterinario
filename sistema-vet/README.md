# Sistema Veterinario

Expediente clínico veterinario: consultas, recetas, autorización de hospitalización, hoja de hospitalización (medicación, constantes, fluidos) y alta.

- App web de un solo archivo (`index.html`), sin servidor.
- Los datos se guardan en el navegador de cada dispositivo (localStorage). **Exporta respaldos** desde Ajustes.
- Versión 0.4 (cápsulas deslizantes, botón +, validación)
